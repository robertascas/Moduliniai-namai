# Šiltas karkasas: logotipas

Ženklas: namo karkasas (gegnės, statramsčiai, apatinis rėmas) su šiltai šviečiančiu langu.
Užrašas: Albert Sans, „Šiltas“ 700, „karkasas“ 400, paversta kontūrais (šrifto diegti nereikia).

| Failas | Naudojimas |
|---|---|
| `logo-horizontalus.svg` / `.png` | Pagrindinis, šviesiame fone |
| `logo-horizontalus-baltas.svg` / `.png` | Tamsiame arba eglės žalios spalvos fone |
| `logo-dvieiliis*.svg` | Siauroms vietoms, iškaboms |
| `zenklas*.svg`, `zenklas.png` | Tik ženklas: profilio nuotraukos, antspaudai |
| `favicon.svg`, `favicon-32.png`, `ikona-512.png` | Naršyklės ir programėlių ikonos |

| Spalva | HEX |
|---|---|
| Eglės žalia | `#0F4C45` |
| Gintarinė (langas) | `#E9A23B` |
| Tamsi (tekstas) | `#16211E` |

Generavimas: `irankiai/textpath.py` (šrifto kontūrai per HarfBuzz) ir `irankiai/mklogo.py`.

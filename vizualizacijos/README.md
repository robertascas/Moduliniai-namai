# 3D vizualizacijos

Laikini svetainės vaizdai, sukurti three.js (namas, pirtis, pirties vidus, sandėliukas, karkasas).
Kai bus tikros darbų nuotraukos, jos pakeis šiuos failus `site/public/img/` aplanke tais pačiais vardais.

```bash
npm install three@0.186.1 playwright
python3 -m http.server 8765 &
node run.js hero:2400:1350 house2:1800:1500 sauna:1800:1500 interior:1600:1600 shed:1600:1600 frame:2000:1400
```
